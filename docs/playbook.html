  • Stay in scope: other fixes become Follow-ups.
  • Caps, fallbacks and guesses are listed under Decisions.
  • Prove it: a failing test before a bug fix, then tests, typecheck and a real run.
  • A fresh, read-only reviewer checks the diff against the task, security included.
  • Parallel only when it's faster; briefs pass pointers, not payloads (delegate).
  • Secrets stay out of the transcript, the code and git history.
  • Enforced by hooks in Claude Code: secret reads, prints, writes and commits are denied; unverified code can't be handed back; you're asked before a push to main, a force push, a merge or discarding uncommitted work.
